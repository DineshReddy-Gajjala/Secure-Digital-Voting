# 🗳️ Secure Digital Voting for the Modern Era

## 🚀 Overview
This project is developed during a hackathon to create a secure, transparent, and efficient digital voting system.

## 🔹 Features
- Secure user authentication
- Real-time voting system
- Transparent vote processing
- User-friendly interface

## ⚙️ Tech Stack
- Backend: Flask (Python)
- Libraries: NumPy, Pandas, Scikit-learn, OpenCV
- Database: SQlite3
